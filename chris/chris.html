✅ Captain's Tips

      

        
🛫 File your flight plan as JFK → MCO via J121 airway for a realistic ATC route.

        
⛅ Expect coastal weather near the Carolinas — check winds aloft before departure.

        
🎯 Start your descent at 130 nm out from MCO. Use 3° descent path: alt = distance × 300.

        
🛬 ILS RWY 17L at MCO is the primary approach. Set NAV1 to 110.9 MHz.

        
🤖 Engage autopilot after 1,000 ft AGL departing JFK — set heading 180° then intercept J121.

        
⚡ Set spoilers ARMED before descent so they auto-deploy on landing rollout.

Startup & Landing Notes — 787-10 in MSFS 2024

Cold & Dark Start Order

Battery ON first, then external power if available. Wait for the EICAS to populate before touching IRS selectors — selecting NAV too early extends alignment time.

APU start only after battery bus is stable; APU bleed air is what gets your air conditioning packs running before engine start.

Engine Start Sequence

Start engine 2 first if using a single APU bleed source (less duct loss to the right engine). Fuel control lever to RUN only once N2 passes roughly 20%, watch for a clean light-off — no EGT exceedance.

FMC / Avionics Setup

Load the route before engine start if possible — it's one less thing competing for your attention during the busy pushback-to-taxi window. Cross-check the takeoff perf page (flaps, V-speeds, stab trim) against your weight and balance before taxi.

Taxi & Before Takeoff

Flaps should be set well before reaching the runway, not on the takeoff roll itself. Flight controls check is a full-deflection check, not a wiggle — MSFS won't fail you for skipping it, but the muscle memory matters if you fly other aircraft.

Approach Stabilization

Aim to be fully configured (gear down, landing flaps, on speed) by 1,000ft AGL on a visual approach, 1,000–1,500ft on an instrument approach. If you're still configuring below that, go around — it's cheaper than a bad landing in both sim and real life.

Landing Technique

The 787's fly-by-wire feel means small late corrections are smoother than big ones. Idle thrust at the flare, not before — carrying a touch of power into the flare gives you a softer touchdown and more predictable pitch authority.

Autobrake & Rollout

Set autobrakes before landing rather than reaching for the panel after touchdown. Speedbrakes should deploy automatically on touchdown if armed — confirm the lever moves, don't just trust the indication.

Shutdown Habits

Run the parking checklist the same way every time, in order. Most "why won't my plane start tomorrow" issues in MSFS trace back to a fuel control lever or battery switch left in the wrong position at shutdown.
